# Karthik Karumanchi: portfolio

Static site served by GitHub Pages from `main` (root).

- `build/build.py` generates every page, the CSS and the JS. Run `python3 build/build.py .`
- `tools/check.py` renders the pages at phone, tablet and desktop in light and dark and reports overflow, tap targets, contrast and alt text. Needs `playwright`.
- `agents/` holds the critic and designer briefs, the owner's critique file, the latest critique and the cycle log.
